- Messaggi italiani e inglesi per i **24 motivi di errore** delle formule nel Workshop.
- Cambiare lingua aggiorna anche un errore già visibile, senza scartare la bozza.
- Save, Share, Export JSON, import e handoff Android conservano diagnostici strutturati.
- Parametri limitati e nomi lunghi leggibili senza tagli, anche su mobile; dati resi come testo,

EN/IT su desktop e mobile. La suite Android comprende 57 test strumentali API 35.

il fallback inglese e non tutte le validazioni strutturali sono tradotte. Accettazione su

## English summary

The web Character Workshop now localizes all 24 formula-error reasons in English and Italian.
Switching language updates existing diagnostics without losing the draft. Long names wrap,
parameters are bounded and displayed as text, and failed saves/imports preserve existing data.
Validation grammar, budgets, Android numerical results and data formats are unchanged.
Real-device and account acceptance checks remain pending.
