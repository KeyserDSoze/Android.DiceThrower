# Dice Thrower 0.0.29 — Preview asincrona dei file personaggio

- La lettura e la decodifica dei file JSON selezionati avvengono fuori dal thread UI.
- La preview e lo stato di caricamento sopravvivono alla ricreazione dell'Activity.
- Una nuova selezione, un link o l'annullamento invalidano le richieste precedenti; i risultati
  tardivi non riaprono preview scartate.
- Limite di 128 KiB, formato JSON, conferma esplicita e dati esistenti restano invariati.
- Nessuna scrittura avviene prima della conferma. La conferma, i link e le impostazioni non fanno
  parte di questa tranche asincrona.

Copertura locale: 411 test JVM e 62 strumentali API 35, build debug/AndroidTest e lint.
Verifiche di release e pubblicazione su Google Play sono da registrare separatamente.

## English summary

Character JSON file reads and decoding now run off the UI thread. Preview state survives Activity
recreation, and cancelled or superseded reads cannot restore stale previews. The existing size
limit, format, explicit confirmation and stored data are unchanged. Release and Google Play
publication checks are tracked separately.
