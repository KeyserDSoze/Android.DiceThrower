# Dice Thrower 0.0.27 — Formule coerenti tra web e Android

## Novità

- Il **Character Workshop web** valida le formule dei tiri con la stessa grammatica Android,
  non soltanto con una whitelist di caratteri: dadi supportati, interi ASCII, operatori,
  parentesi e segni unari.
- Controlla **overflow e budget** prima di salvare o condividere: 100 dadi per termine, 500
  per espressione, 1000 termini, 4096 caratteri e 32 livelli di nesting.
- Variabili, milestone `levelstep` e regole di livello sono verificate anche dopo la loro
  espansione al livello corrente. Un tiro configurato sul web non può più superare quei
  limiti soltanto dopo il trasferimento nell'app.
- Le vecchie voci browser restano **leggibili e correggibili**: nessuna eliminazione o
  riscrittura automatica. Un salvataggio non valido lascia intatto il record precedente.
- **Export JSON** mostra nell'interfaccia gli errori di validazione invece di lasciarli
  uscire come eccezioni non gestite; la bozza rimane modificabile.
- I campi legacy senza `includeInNormalRoll` mantengono il significato nativo `true`.
- Un **corpus condiviso di 92 casi** viene eseguito sia dal validatore web sia dai parser
  Android reali, per mantenere verificabile la compatibilità futura.

## Compatibilità

Prima di salvare, esportare o condividere un personaggio browser legacy, correggere eventuali
formule che il vecchio controllo accettava ma Android rifiuta, ad esempio `1d7`, `1d6/2`,
espressioni incomplete o valori fuori intervallo. `×` e formule valide fino a 4096 caratteri
sono ora accettati coerentemente. Le formule originali valide non vengono normalizzate nei dati.

Nessuna modifica a RNG, risultati logici, personaggi/storico Android, formati di backup,
trasferimento o sync Drive. La grammatica degli effetti aritmetici (`f/c/r`, divisione,
decimali e riferimenti alle Parts) resta separata da quella dei dadi: non viene eseguita
nel browser. È consigliato un backup prima di aggiornare l'app.

## English summary

The web Character Workshop now mirrors Android roll-formula grammar, overflow checks and
dice/size budgets, including resolved variables and expanded level rules. Existing browser
records remain readable and editable without automatic rewriting; invalid saves leave the
previous record intact. JSON export reports validation errors in the UI instead of throwing
an uncaught event-handler exception. A shared 92-case corpus exercises the actual native and web parsers.

Correct previously accepted incompatible legacy formulas before saving/exporting/sharing.
Android RNG, numerical results, history and data/transfer formats are unchanged. Advanced
effect arithmetic remains a separate grammar. Real-device, camera and account acceptance
checks remain pending; this release does not close EPIC #165.
